Each task in this project is based on real-life applications, which made the learning more practical and useful. The work done in this repository reflects my understanding and learning throughout the course.

The repository is organized into different folders, each representing a specific task:

📝 Tasks Overview

🔹 Task 1 – Infographic

Created a one-page infographic explaining digital literacy, safe internet practices, and online professionalism using Canva.

🔹 Task 2 – Digital Portfolio

Set up and updated profiles on GitHub, LinkedIn, and Kaggle to build a professional online presence.

🔹 Task 3 – Platforms

Completed a beginner-level coding problem on HackerRank and created a Google Form for digital literacy awareness.

🔹 Task 4 – Email Etiquette

Drafted professional emails and created a checklist for responsible social media usage.

🔹 Task 5 – Cybercrime Awareness

Prepared a case study on UPI fraud and created a prevention checklist to spread awareness about online safety.
